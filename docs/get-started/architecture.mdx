<div id="three-pillars-architecture" className="scroll-mt-24 mb-8">
  ## The 3 Architectural Layers

### 1. The Specification Standard (`liate.json` + `skills.md`)
- Single declarative document defining AI models, prompts, tools, and procedural rules.
- 100% portable — runs identically on OM (locally) or in the Liate Cloud.

### 2. The Local Runtime: OM (`@tryliate/om`)
- Built in **TypeScript / Bun** on top of the **Hono v4 edge router**.
- Manages multi-turn ReAct loops, token optimization, and MCP child process lifecycles.
- Flat-file storage at `~/.liate/` ensures zero database setup is required for local development.

### 3. The Sovereign Cloud: Liate Platform
- **Compute**: Hardware-isolated AWS Firecracker MicroVM in Mumbai (`ap-south-1`) per user. Boots in < 30ms with $0.00 idle cost.
- **Database (BYOD)**: Developer's private Supabase PostgreSQL database storing `liate_agents` specs in native `JSONB` and vector memory via `pgvector`.
- **Protocol**: Single agents run via `AgentAntra` (`Ekanantra v1` on `:7071`); agent swarms run via `AgentSutra` (`Google A2A + ADK` on `:7072`).
