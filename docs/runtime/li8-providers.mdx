<div id="overview" className="scroll-mt-24 mb-8">

OM provides **zero-dependency, native HTTP dispatch** for all leading AI model providers. You bring your own API keys (**BYOK**) — you pay only the AI provider directly with zero markup or intermediary token taxes.

Specify any provider and model in the **L-Pillar**:

```json
{
  "L": "sarvam/sarvam-105b-conversations"
}
```

</div>

<div id="byok-management" className="scroll-mt-24 mb-8">
  ## Managing Your API Keys
  <div className="text-sm text-black/70 dark:text-white/70 mb-4">
    You can configure your keys via CLI, REST API, or by directly editing <code>~/.liate/.env</code>:
  </div>

```bash
# Save a key directly to ~/.liate/.env
echo "SARVAM_API_KEY=sk_live_your_key" >> ~/.liate/.env
echo "ANTHROPIC_API_KEY=sk-ant-your_key" >> ~/.liate/.env

# Or save via the OM REST API
curl -X POST http://localhost:7071/api/keys \
  -H "Content-Type: application/json" \
  -d '{"provider": "sarvam", "key": "sk_live_your_key"}'
```

</div>
