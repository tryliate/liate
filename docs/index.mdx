## What is Liate?

**Liate** is India's first open-source, sovereign AI agent runtime. Describe your agent in a single **`liate.json`** file — model, tools, memory, skills, and environment — and execute it anywhere: your laptop, a VPS, Cloudflare Workers, or a dedicated Liate Cloud MicroVM.

The open-source runtime is called **OM** (`🕉️`). It is built on **Bun** and **Hono** — the fastest JavaScript runtime and edge HTTP framework available today. No Python. No pip lockfiles. No Docker required.
