## What is Liate?

**Liate** is not a framework. It is a **runtime** — the same way Bun is a runtime for JavaScript, Liate is a runtime for AI agents.

You don't install Liate as a library on top of something else. You **run ON Liate**. Your agent boots in **~430ms** as a fully-fledged production server with **35+ REST + WebSocket endpoints** — zero infra, zero setup, zero framework overhead.

> *"Every Agent is an API."*  
> Write 6 lines of OOP. Get a production serverless AI agent backend. That's BaaA — Backend as an Agent.

## The Vision

**Agentantra** is the sovereign operating framework for autonomous AI agents.

In a world dependent on opaque cloud APIs, **Liate** provides complete local independence:

- **Open Source. Free Forever**: Run 100% free locally in a single 94MB binary with zero cloud dependency.
- **5-Pillar Architecture (L-I-A-T-E)**:
  - **L** — **Model** (`LiateModel`): Multi-provider engine (Sarvam 105B, Ollama, Claude, Gemini, local models).
  - **I** — **Integration** (`LiateIntegration`): Persistent memory & session state.
  - **A** — **Agent** (`LiateAgent`): Typed OOP agent identity and intent.
  - **T** — **Tools** (`LiateTools`): Native MCP (Model Context Protocol) and function tools.
  - **E** — **Environment** (`LiateEnv`): Sandboxed execution, turn budgets, and cost guardrails.
- **OOP First**: Every object-oriented class is an autonomous agent; every agent is a clean, typed class.
- **Sarvam AI Startup Program**: Proudly building with India's frontier foundation model ecosystem.
- **DPDP Compliant**: Native data protection adhering to India's Digital Personal Data Protection Act.
- **From Bharat To The World**: Open-source, free, and built for developers everywhere.
